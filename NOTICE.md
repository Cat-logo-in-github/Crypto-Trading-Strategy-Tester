# Attribution and distribution notes

Hypothesis Lab renovates the user-supplied local archive of [Cat-logo-in-github/Crypto-Trading-Strategy-Tester](https://github.com/Cat-logo-in-github/Crypto-Trading-Strategy-Tester). Original Bitcoin Trading Bot and Research Wing source, documentation and screenshots remain under `legacy/`; the original README is preserved there. The original source archive contained no license file in the inspected project files. Copyright in that work remains with its author and contributors. The MIT license in this repository applies to newly authored renovation code and documentation; it does not fabricate permission from any other original contributor. The repository owner should confirm rights to original contributions before public redistribution.

No third-party engine source was copied into the supported application. LEAN, NautilusTrader, backtesting.py, scikit-learn, Gymnasium, Stable-Baselines3, Optuna and MLflow were evaluated, not silently vendored. Optional packages retain their own license notices when installed. See the audit's linked primary sources.

The bundled market and weather CSV fixtures are newly generated synthetic data provided under the same MIT terms as the new application. Their apparent instrument, prices and geographic labels are illustrative. They are not exchange history or observations of a real town.

Original downloaded datasets, local credential files, bot logs, environments and Git history are excluded from this distribution. The user's original ZIP is unchanged and remains the preservation copy for those items. Third-party data fetched later by a user is local state and is not included by the release packager.

Open-Meteo data has CC BY 4.0 attribution requirements; free API access is restricted to noncommercial use and current quotas. Kraken and Alpha Vantage data access and reuse remain subject to their terms. A public API is not a blanket redistribution license. Do not put fetched provider data, credentials or private research into the public Pages site.
